# MindOdyssey — page de présentation

Jeu éducatif d'aventure et de construction pour le **CE1 à la 6ᵉ**, 7-12 ans.
Dix époques réelles, soixante missions sourcées, un village qui grandit.
Sans classement entre enfants, sans note, sans compte à créer pour l’enfant.

---

Ce dépôt ne contient **que la page publiée** : `index.html`, `favicon.svg`,
`assets/` et `theme/`. C'est la sortie d'un build, pas des fichiers à modifier —
les sources vivent dans le dépôt de conception, qui reste privé.

## Publier

1. **Settings** → **Pages**
2. *Source* : **Deploy from a branch**
3. *Branch* : **main**, dossier **`/ (root)`**
4. **Save**, puis une à deux minutes

L'URL apparaît en haut de cette même page.

## Ce que la page ne fait pas

- **Aucune requête vers un tiers.** Les polices sont servies depuis ce dépôt et
  non depuis Google Fonts : aucune adresse IP de visiteur ne part ailleurs.
- **Aucun cookie, aucun traceur, aucun script de mesure d'audience.**
- Le formulaire de pré-inscription n'envoie rien tant que son point de collecte
  n'est pas renseigné dans les sources.
